# 🛠️ TechFix - Suporte Técnico, Manutenção & Peças

Portfólio web moderno e responsivo desenvolvido para divulgação de serviços de assistência técnica em computadores desktop, notebooks, smartphones e suporte remoto.

## 🚀 O que o projeto oferece:
- **Computadores Desktop:** Montagem de PCs customizados/gamers, limpeza preventiva, formatação e upgrade de componentes (SSD, RAM, Placas de Vídeo, Processadores, Fontes).
- **Notebooks:** Troca de telas, teclados, baterias, carcaças e otimização de desempenho.
- **Smartphones:** Reparo de displays, alto-falantes, baterias, conectores e câmeras.
- **Venda de Peças & Acessórios:** Fornecimento de componentes de alta performance.
- **Blog Integrado:** Artigos educativos sobre hardware e dicas de preservação de equipamentos.
- **Orçamento Direto via WhatsApp:** Integração automatizada para conversão rápida de clientes.

## 💻 Tecnologias Utilizadas
- **HTML5 & CSS3** (Estrutura e estilização moderna)
- **Tailwind CSS** (Design responsivo e estilização ágil via CDN)
- **JavaScript (Vanilla)** (Interatividade, modais de artigos e redirecionamento de orçamento)
- **FontAwesome** (Ícones vetoriais)
